# DeepLearningC：用 C 实现 LeNet-5

这是一个用于学习卷积神经网络的项目，使用 C 手写前向传播、反向传播和参数更新，完成 MNIST 手写数字分类。网络由 GCC 编译运行，不依赖深度学习框架；另提供 Python/Tkinter 手写画板，调用同一个 C 程序识别数字。

目前已经实现 LeNet-5 的主要网络结构，包括部分连接卷积、可训练下采样、缩放 tanh 和固定模板 RBF 输出。训练采用普通 SGD，部分配置与原论文不同，因此本项目是学习实现，不宣称完整复现论文实验。

## 项目来源

**本项目的主要代码框架基于 [tostq/DeepLearningC](https://github.com/tostq/DeepLearningC) 改造，并非从零独立编写。** 原项目提供了CNN的数据结构、矩阵与卷积运算，以及前向传播、反向传播和训练的基础框架。

本仓库在原项目基础上进行学习和修改，主要包括：整理为C11/GCC构建，逐步改造LeNet-5各层及RBF输出，调整初始化和模型保存方式，增加训练进度、耗时日志及手写识别窗口。感谢原作者提供的代码和教程。

- 原始GitHub仓库：[tostq/DeepLearningC](https://github.com/tostq/DeepLearningC)
- 原作者教程：[用C语言实现卷积神经网络相关教程](http://blog.csdn.net/tostq/article/details/51786265)

## 快速开始

在项目根目录执行。需要GCC和Make，并已将四个MNIST IDX文件解压到`CNN/Minst/`；手写窗口还需要Python 3和Tkinter。

```sh
# 1. 编译
make

# 2. 从头训练：默认10轮，学习率0.001，固定随机种子42
./build/cnn train \
    CNN/Minst/train-images-idx3-ubyte \
    CNN/Minst/train-labels-idx1-ubyte \
    CNN/CNN/lenet5_quickstart.cnn --seed 42

# 3. 用测试集评估刚训练好的模型
./build/cnn test \
    CNN/Minst/t10k-images-idx3-ubyte \
    CNN/Minst/t10k-labels-idx1-ubyte \
    CNN/CNN/lenet5_quickstart.cnn

# 4. 启动手写窗口，在窗口中选择上面的模型文件
make gui
```

模型在训练结束后保存；同名模型会被覆盖。进度和耗时追加到`CNN/CNN/lenet5_quickstart.cnn.train.log`。已有兼容模型时，可跳过训练，直接测试或在窗口中加载。

环境安装、数据文件说明及更多用法见后面的“编译与运行”。

## 1. LeNet-5 是什么

LeNet-5 是 LeCun 等人在 1998 年论文中介绍的卷积神经网络，可用于手写字符识别。它通过卷积提取局部特征，通过下采样缩小特征图，再将这些特征组合成用于分类的表示。

本项目识别数字 0–9。一张图片经过网络后得到10个距离，距离最小的类别就是预测结果。

层名中的字母表示：

- **C：卷积层**，例如 C1、C3、C5。
- **S：下采样层**，例如 S2、S4。
- **F：全连接层**，例如 F6。
- **O7：输出层**，这是本代码对 RBF 输出层的命名。

不计算输入层，共有7个计算层。其中 C1 至 F6 含可训练参数，本实现的 RBF 模板固定不训练。原论文见 [Gradient-Based Learning Applied to Document Recognition，第 II 节](https://princetonuniversity.github.io/NEU-PSY-502/_static/pdf/Class%204/LeCunn1998.pdf)。

## 2. 网络结构与输入输出

下面统一用 **高 × 宽 × 通道数** 表示特征图尺寸。卷积层步长为1、不填充；下采样使用不重叠的2×2窗口，步长为2。

```text
MNIST图片 28×28×1
    ↓ 像素归一化，四周各填充2个背景像素
输入      32×32×1
    ↓ C1：5×5卷积 + 偏置 + 缩放tanh
          28×28×6
    ↓ S2：2×2可训练下采样 + 缩放tanh
          14×14×6
    ↓ C3：5×5部分连接卷积 + 偏置 + 缩放tanh
          10×10×16
    ↓ S4：2×2可训练下采样 + 缩放tanh
           5×5×16
    ↓ C5：5×5卷积 + 偏置 + 缩放tanh
           1×1×120
    ↓ 展平，F6：全连接 + 偏置 + 缩放tanh
           84个数
    ↓ O7：与10个固定模板计算平方欧氏距离
           10个距离 → 选择距离最小的数字
```

| 层 | 输入 | 输出 | 主要操作 | 可训练参数数目 |
|---|---|---|---|---:|
| C1 | 32×32×1 | 28×28×6 | 6组5×5卷积核，提取局部特征 | 156 |
| S2 | 28×28×6 | 14×14×6 | 每通道独立的可训练下采样 | 12 |
| C3 | 14×14×6 | 10×10×16 | 按连接表组合部分输入通道 | 1,516 |
| S4 | 10×10×16 | 5×5×16 | 每通道独立的可训练下采样 | 32 |
| C5 | 5×5×16 | 1×1×120 | 每个输出连接全部16个输入通道 | 48,120 |
| F6 | 120个数 | 84个数 | 全连接，得到用于匹配模板的表示 | 10,164 |
| O7 / RBF | 84个数 | 10个距离 | 与数字0–9的固定模板比较 | 0 |
| **合计** | | | | **60,000** |

RBF另有10×84＝840个固定模板值，不计入可训练参数。C3断开连接的内存槽也不计入有效参数。

## 3. 每一层做了什么

### 3.1 输入：28×28变为32×32

MNIST图片文件中，每张图片有784个灰度字节，0表示背景，255表示笔画。读取时执行：

```c
pixel = -0.1f + 1.275f * (gray / 255.0f);
```

因此背景变为−0.1，最亮笔画变为1.175。之后在上、下、左、右各填充2个值为−0.1的像素，得到32×32输入。原始图片不缩放。

训练、测试和手写识别使用相同的预处理。

### 3.2 C1：从图片提取6张特征图

每个5×5卷积核在图片上滑动，计算局部加权和，加上该输出通道的偏置，再经过激活函数。空间尺寸变为：

```text
32 - 5 + 1 = 28
```

6组卷积核得到6张28×28特征图。每张特征图上的所有位置共享同一组卷积核及一个偏置。

参数量：`(5×5×1 + 1) × 6 = 156`。

### 3.3 S2：可训练下采样

S2对每个通道分别处理。将每个2×2窗口内的4个值相加，乘以该通道的可训练系数a，加上偏置b，再激活：

```text
sum = x00 + x01 + x10 + x11
z   = a × sum + b
y   = f(z)
```

它不是最大池化，也不是固定求平均：a、b会随着训练改变。同一通道内所有窗口共享一对a、b。

空间尺寸从28×28变为14×14，通道数仍为6。参数量：`6 × 2 = 12`。

### 3.4 C3：部分连接卷积

C3输出16张特征图，但每个输出不一定连接S2的全部6个通道。对连接的输入通道分别做5×5卷积，将结果相加，最后加偏置并激活。

连接规则按照原论文Table I设置，下标从0开始：

| C3输出通道 | 连接的S2输入通道 |
|---|---|
| 0 | 0、1、2 |
| 1 | 1、2、3 |
| 2 | 2、3、4 |
| 3 | 3、4、5 |
| 4 | 0、4、5 |
| 5 | 0、1、5 |
| 6 | 0、1、2、3 |
| 7 | 1、2、3、4 |
| 8 | 2、3、4、5 |
| 9 | 0、3、4、5 |
| 10 | 0、1、4、5 |
| 11 | 0、1、2、5 |
| 12 | 0、1、3、4 |
| 13 | 1、2、4、5 |
| 14 | 0、2、3、5 |
| 15 | 0、1、2、3、4、5 |

共 `6×3 + 9×4 + 1×6 = 60` 组有效5×5卷积核。

- 空间尺寸：`14 - 5 + 1 = 10`。
- 参数量：`60 × 25 + 16 = 1,516`。
- 当前内存仍分配6×16组核，但无效连接为零，前向、反向、更新和模型保存均跳过这些连接。

### 3.5 S4：再次下采样

计算方式与S2相同，仍然是窗口求和、乘共享系数、加偏置、激活。

输入10×10×16，输出5×5×16。参数量：`16 × 2 = 32`。

### 3.6 C5：把空间特征组合成120个数

每个输出通道使用一组5×5×16的卷积核，覆盖S4全部16张5×5特征图。因为输入和卷积核的空间尺寸相同，每个输出通道只得到一个值：

```text
5 - 5 + 1 = 1
```

120个输出通道构成1×1×120，可以直接展平成120维向量。

参数量：`(5×5×16 + 1) × 120 = 48,120`。

### 3.7 F6：120维变为84维

F6包含84个神经元，每个神经元连接C5的全部120个输出：

```text
z[j] = sum_k(w[j][k] × x[k]) + b[j]
y[j] = f(z[j])
```

参数量：`120 × 84 + 84 = 10,164`。

84个输出用于与RBF模板匹配；84对应模板的7列×12行，不代表84个类别。

### 3.8 O7：RBF输出与分类

数字0–9各有一个固定的84维模板，模板的笔画为+1、背景为−1。将F6输出与每个模板计算平方欧氏距离：

```text
D[j] = sum_k (F6.y[k] - template[j][k])²
预测数字 = 距离D最小的类别
```

这里比较的是F6学到的84维表示，不是直接将原始图片与字模比较。RBF没有可训练偏置，也不再经过tanh或softmax。输出距离越小越匹配，不是概率。

## 4. 激活、反向传播和初始化

C1、S2、C3、S4、C5、F6都使用缩放tanh：

```text
f(z) = 1.7159 × tanh((2/3) × z)
```

各层先加偏置，再调用单参数`activation_Sigma(z)`。卷积层及F6的主要中间变量为：

| 变量 | 意义 |
|---|---|
| `v` | 加偏置后、激活前的z |
| `y` | 激活后的输出f(z) |
| `d` | 损失对z的偏导数，用于继续反传和计算参数梯度 |

`cnnff`按层计算前向结果；`cnnbp`从RBF反向计算到C1；`cnnapplygrads`更新参数；`cnnclear`清空当前样本的中间结果。每处理一个训练样本就更新一次参数。

本实现采用数学定义的卷积，即对核翻转后做互相关；反向传播使用与此前向约定配套的索引。

训练损失采用论文式(9)的MAP形式：

```text
L = D[target] + log(exp(-J) + sum_j exp(-D[j]))
J = 10
```

代码使用稳定的log-sum-exp计算。训练日志里的`smoothed loss`是该损失的指数平滑值，不是整轮平均损失，也不是错误率。

连接权重按照论文附录A的范围，从`[-2.4/F, 2.4/F]`均匀采样，F为实际输入连接数：

| 参数 | F | 初始范围 |
|---|---:|---|
| C1卷积核 | 25 | ±0.096 |
| C3连接3路的输出核 | 75 | ±0.032 |
| C3连接4路的输出核 | 100 | ±0.024 |
| C3连接6路的输出核 | 150 | ±0.016 |
| C5卷积核 | 400 | ±0.006 |
| F6权重 | 120 | ±0.020 |
| S2/S4共享系数 | 4 | ±0.600 |

偏置初始化为0。随机种子只在程序入口设置一次，各层连续使用同一随机序列；可通过`--seed`固定种子。

## 5. 与原版论文的对应和差异

对照对象是1998年论文中的LeNet-5数字识别网络，不是论文涵盖的整套文档识别系统。结构和训练实验需要分别看待。

| 项目 | 当前实现与原论文的关系 |
|---|---|
| 网络尺寸及通道数 | C1至F6的尺寸、通道数与主要结构一致 |
| C3部分连接 | 使用Table I的连接表，共60组有效卷积核 |
| 下采样与激活 | 实现可训练系数、偏置及缩放tanh，没有替换为最大池化或ReLU |
| 权重初始化 | 采用附录A的`±2.4/F`范围；下采样共享系数也按窗口输入数应用此规则 |
| 偏置初始化 | 保留全零，这是实现约定；未确认与原作者全部初值细节一致 |
| RBF字模 | 使用手工重绘的7×12数字模板，并非原作者字模的逐位复刻；模板固定不训练 |
| MAP损失 | 公式形式对应论文式(9)，但`J=10`未核实为原实验值 |
| 优化器 | 当前为普通逐样本SGD；没有实现论文附录C的随机对角Levenberg–Marquardt方法及曲率估计 |
| 学习率和轮数 | 当前默认10轮、固定0.001；论文第III-B节对应实验使用20轮及分阶段下降的全局学习率 |
| 样本顺序 | 当前每轮按文件顺序；没有实现随机抽样或打乱，未对齐原实验具体序列 |
| 数据增强 | 当前无增强；论文分别报告不使用增强和使用随机几何变换的实验 |
| 拒识 | 当前始终从0–9中选一个结果，没有自动拒绝非数字输入的功能 |
| 实验结果 | 未完成同等实验条件下的对照，不能把论文准确率当作本项目成绩 |

原论文的学习率计划与其优化器配套，不能仅修改几个学习率数值就认为训练方法已经一致。当前项目侧重理解网络各层和梯度计算，保留这些差异是明确的学习范围选择。

依据：[原论文第II节、III-B节和附录A–C](https://princetonuniversity.github.io/NEU-PSY-502/_static/pdf/Class%204/LeCunn1998.pdf)。

## 6. 编译与运行

下面所有命令都在项目根目录执行。

### 6.1 环境与编译

C程序需要GCC、GNU Make和系统数学库，目标环境为Linux。Makefile使用C11，数学库通过`-lm`链接；训练计时使用POSIX单调时钟。

```sh
make
./build/cnn --help
```

生成程序：`build/cnn`。手写窗口额外需要Python 3和Tkinter，不需要NumPy或Pillow。Ubuntu/Debian缺少依赖时可安装：

```sh
sudo apt install build-essential python3-tk
```

### 6.2 准备MNIST数据

将MNIST的四个IDX文件解压到`CNN/Minst/`，或者在运行命令中填写实际路径：

```text
CNN/Minst/
├── train-images-idx3-ubyte   # 60,000张训练图片
├── train-labels-idx1-ubyte   # 60,000个训练标签
├── t10k-images-idx3-ubyte    # 10,000张测试图片
└── t10k-labels-idx1-ubyte    # 10,000个测试标签
```

这些是包含文件头和像素/标签数据的二进制文件，不是PNG/JPEG图片。程序读取未压缩的IDX文件，不能直接传入`.gz`压缩包。

### 6.3 训练自己的模型

```sh
./build/cnn train \
    CNN/Minst/train-images-idx3-ubyte \
    CNN/Minst/train-labels-idx1-ubyte \
    CNN/CNN/lenet5_rbf.cnn
```

默认使用全部输入样本，训练10轮，学习率0.001。每轮遍历一次训练集。轮数和学习率在`CNN/CNN/main.c`的以下位置设置，修改后重新执行`make`：

```c
CNNOpts options = {10, 0.001f};
```

需要固定随机种子时，在命令末尾添加`--seed 42`：

```sh
./build/cnn train \
    CNN/Minst/train-images-idx3-ubyte \
    CNN/Minst/train-labels-idx1-ubyte \
    CNN/CNN/lenet5_seed42.cnn --seed 42
```

不指定种子时使用当前时间。同一程序、C运行库、数据和设置下，固定种子可以重复初始化和训练；不同平台的`rand()`序列可能不同。

**每次执行`train`都从新初始化开始，不是继续训练已有模型。** 模型在全部训练完成后保存，目标文件已存在时会被覆盖；请使用不同文件名保存不同实验。输出目录必须事先存在。

### 6.4 查看进度和耗时

终端显示当前轮数、样本进度、平滑损失及累计耗时，每轮结束还显示该轮耗时，训练结束显示总耗时。

日志自动追加到`模型路径.train.log`，包含种子、开始时间、进度和耗时。例如：

```sh
tail -n 20 CNN/CNN/lenet5_rbf.cnn.train.log
```

计时统计训练函数内实际经过的时间，不包含数据加载、网络初始化及模型保存。重复训练追加新日志；中途停止时已经写出的记录仍在，但没有该次训练完成的总耗时或新模型。

### 6.5 测试准确率

```sh
./build/cnn test \
    CNN/Minst/t10k-images-idx3-ubyte \
    CNN/Minst/t10k-labels-idx1-ubyte \
    CNN/CNN/lenet5_rbf.cnn
```

程序输出样本数、准确率和错误率。这里的`test`是对数据集评估模型，不是源码单元测试；项目不保留临时验证代码，也没有`make test`目标。

### 6.6 在窗口中手写识别

```sh
make gui
```

也可以运行`python3 gui.py`；指定解释器可用`make gui PYTHON=/path/to/python3`。

1. 点击“选择”，加载训练生成的模型，例如`CNN/CNN/lenet5_rbf.cnn`。
2. 在28×28网格中左键书写，右键擦除。
3. 点击“识别”或按回车，查看预测数字和各类别距离。
4. 点击“清空重写”识别下一张。

画板不裁剪、不缩放、不自动居中；网格线不进入模型。C程序负责填边及归一化。绿色柱表示最小距离对应的类别，距离不是概率。鼠标书写的位置、大小及笔迹与训练样本不同，都可能影响识别结果。

### 6.7 命令行识别单张图片

```sh
./build/cnn predict CNN/CNN/lenet5_rbf.cnn < pixels.raw
```

`pixels.raw`必须恰好包含784个灰度字节，按行存储28×28像素，0为背景、255为笔画，没有文件头。不要直接传入PNG、JPEG或完整IDX文件。

输出为JSON：`digit`是预测数字，`scores`是数字0–9的平方距离，`score_type`为`squared_distance`。

### 6.8 模型兼容与清理

当前模型格式标识为`DLCRBF01`，保存可训练参数、连接表、固定模板及损失配置。加载时会校验这些信息。仅修改初始化方式不会使已有模型失效，但更换模板、结构或不兼容配置后需要重新训练。

早期的`DLCF6V01`、`DLCC5V01`、`DLCSPC01`、`DLCPOOL1`模型不兼容当前网络。文件名本身不能判断格式；模型文件使用本机整数和浮点格式，不是通用的跨平台交换格式。

```sh
make clean
make
```

`make clean`会删除整个`build/`目录，因此不要把需要长期保留的模型或日志存放在那里。
