# DeepLearningC

使用标准 C11 手写的 MNIST 卷积神经网络，参考 LeNet-5，无深度学习框架依赖。
当前已接通32×32输入、缩放tanh、可训练下采样、C3部分连接、C5、F6和固定模板RBF输出。
网络结构按LeNet-5实现；字模为手工重绘，优化器仍为普通SGD，不声称逐位或逐实验复现原论文。

## 使用 GCC 构建

在项目根目录执行：

```sh
make
./build/cnn --help
```

需要 GCC、GNU Make 和系统数学库（链接参数 `-lm`）。Makefile 默认使用 `gcc`，
开启 `-std=c11 -Wall -Wextra -Wpedantic`；执行 `make clean` 清理构建目录。

## 测试与训练

自行准备并解压 MNIST 的 IDX 图片、标签文件，数据文件是否存在取决于本地环境，Git不跟踪数据集。
参数中的路径按实际文件名填写（测试集通常使用 `t10k-` 前缀）：

```sh
./build/cnn train CNN/Minst/train-images-idx3-ubyte CNN/Minst/train-labels-idx1-ubyte build/trained.cnn
./build/cnn test CNN/Minst/t10k-images-idx3-ubyte CNN/Minst/t10k-labels-idx1-ubyte build/trained.cnn
```

测试输出准确率和错误率。训练默认使用全部输入样本、10 个 epoch、学习率 0.001，
并将模型写入最后一个参数指定的位置；该位置已有文件会被覆盖。
模型采用 `DLCRBF01` 格式：8字节标识、17个原生int结构字段、C1/C3/C5连接表（每连接1字节），
接着保存RBF背景惩罚j（1个float）和固定字模（840个0/1字节），
随后保存C1、C3、C5有效连接的卷积核与偏置、F6权重与偏置，
以及S2、S4的缩放系数与偏置；float及整数使用本机格式，尚非跨平台交换协议。
加载时检查版本、结构、连接表、RBF配置和数据完整性。之前的`DLCF6V01`、`DLCC5V01`、`DLCSPC01`、`DLCPOOL1`以及旧的 `minst.cnn`、`my_model.cnn` 不适用于新网络，
需要重新训练；原文件未被删除或覆盖。`make clean` 会删除build目录，包括其中的模型。
RBF损失的梯度尺度与旧输出不同，默认学习率已降为0.001；这不是论文的二阶优化及学习率方案。
日志显示MAP损失的指数平滑值，与之前的十维平方误差数值不可直接比较。完整数据集准确率未验证。

## 训练耗时记录

训练时显示累计耗时，每轮结束显示该轮耗时，最后显示总训练耗时（秒及`时:分:秒`）。
计时使用单调时钟，统计实际经过的时间，包括等待/被系统调度的时间，
从进入训练函数到训练循环结束，不包含数据加载、网络初始化和模型保存。

进度、开始日期时间、每轮及总耗时自动追加到`模型路径.train.log`。
例如模型`CNN/CNN/lenet5_rbf.cnn`对应日志`CNN/CNN/lenet5_rbf.cnn.train.log`：

```sh
tail -n 20 CNN/CNN/lenet5_rbf.cnn.train.log
```

每条记录立即刷新；中断训练时已写入的进度仍可查看，但不会生成完成耗时。
重复训练会追加新的记录，模型文件本身仍按原行为覆盖。

## 手写识别桌面窗口

在项目根目录运行：

```sh
make gui
```

窗口使用 Python 3 自带的 Tkinter（当前系统已可用），不依赖 Pillow、NumPy 或深度学习框架。
也可以先 `make`，再执行 `python3 gui.py`。若指定 Python 解释器，使用
`make gui PYTHON=/path/to/python3`。

1. 点击「选择」加载本分支重新训练生成的模型（例如 `build/trained.cnn`）。旧默认模型会被拒绝。
2. 在 28×28 像素网格上用鼠标左键书写，右键擦除。每格对应一个像素，可多画几笔加粗。
3. 点击「识别」或按回车，显示预测数字、实际输入预览和 0–9 的平方距离。
4. 点击「清空重写」开始下一个数字；也可以补画后再次识别。

画板直接存储 28×28 个像素（黑色 0、白色 255），不裁剪、不缩放、不自动居中。
每格在屏幕上显示为 10×10，方便鼠标操作；网格线及田字中线仅用于辅助书写，不进入模型。
GUI 将这 784 个灰度字节通过标准输入传给 `build/cnn predict MODEL`，
实际前向计算仍使用 GCC 编译的 C 代码，每次识别在独立子进程中完成。
C端与训练一致：四周填充2像素到32×32，归一化到[-0.1, 1.175]；窗口预览显示的是填边前的28×28网格。
距离为F6输出到各数字模板的平方欧氏距离，越小越匹配；绿色柱对应最小值。
图表按本次最大距离调整柱高，标注保留原始距离。距离不是概率，也不代表识别准确率。
`predict`的JSON保留`scores`数组，并增加`score_type: "squared_distance"`说明其含义。
模型只学习了 0–9，非数字图形也可能被预测为某个数字；鼠标手写效果可能低于 MNIST 测试集准确率。

当前结构（高×宽×通道）：32×32×1 → C1 28×28×6 → S2 14×14×6 →

## C3部分连接

连接规则采用[LeNet-5原论文Table I](https://yann.lecun.com/exdb/publis/pdf/lecun-98.pdf)。
`connectModel[input*outChannels+output]`表示一对通道是否连接。
C1保持全部连接；C3的输出通道和对应输入通道如下（下标从0开始）：

| C3输出 | S2输入通道 |
|---|---|
| 0 | 0,1,2 |
| 1 | 1,2,3 |
| 2 | 2,3,4 |
| 3 | 3,4,5 |
| 4 | 0,4,5 |
| 5 | 0,1,5 |
| 6 | 0,1,2,3 |
| 7 | 1,2,3,4 |
| 8 | 2,3,4,5 |
| 9 | 0,3,4,5 |
| 10 | 0,1,4,5 |
| 11 | 0,1,2,5 |
| 12 | 0,1,3,4 |
| 13 | 1,2,4,5 |
| 14 | 0,2,3,5 |
| 15 | 0,1,2,3,4,5 |

共60个有效5×5核，C3可训练参数为60×25+16=1516。
为保留已有四维指针结构，内存仍分配6×16组核；断开槽初始化为0，
前向、输入梯度和参数更新都跳过断开连接，模型文件也不保存这些无效槽。
加载后无效槽重新清零。当前C1至F6合计60000个可训练参数；RBF的840个固定模板值不参与训练。

## C5卷积层

C5使用120组5×5×16卷积核，每个输出通道连接S4全部16个通道。
步长1、不填充，空间大小为5−5+1=1，因此得到1×1×120。
卷积累加后加每通道偏置，并使用缩放tanh激活；参数量为(5×5×16+1)×120=48120。

`c5ff`使用翻转下标完成数学卷积；`cnnbp`计算C5的dL/dz，并传回S4；
`cnnapplygrads`更新C5卷积核和偏置，`cnnclear`清空其特征图与局部梯度。
模型保存和加载已包含C5参数，原结构的模型需要重新训练。

## F6全连接层

F6复用`OutLayer`数据结构，接收C5展平后的120个值，输出84个值。
每个神经元执行`z=sum(w*x)+b`，然后`y=1.7159*tanh((2/3)*z)`。
参数量为120×84+84=10164；`v`保存含偏置的z，`y`保存激活结果，`d`保存dL/dz。

反向传播先由RBF求F6输出的梯度，乘激活导数得到F6的d，再通过F6权重传回C5。
更新时权重梯度为`d[j]*C5.y[k]`，偏置梯度为`d[j]`。
模型文件包含全部F6权重和偏置。

所有层统一先完成加偏置，再调用单参数`activation_Sigma(z)`。
C1、C3、C5及F6的`v`统一保存含偏置的z；下采样层用局部变量z。
这一接口整理不改变网络计算结果，已有`DLCRBF01`模型可直接使用。

## RBF输出与损失

依据[原论文第II节、式(7)/(9)及Fig.3](https://princetonuniversity.github.io/NEU-PSY-502/_static/pdf/Class%204/LeCunn1998.pdf)，
每类固定一个84维模板，对应7列×12行的数字，按行展平，笔画+1、背景−1。
`rbf.c`内字模为依照这一设计手工重绘的0–9，并非原始字模文件的逐位复刻。
本实现固定模板，不更新RBF中心；没有输出层偏置，也不再对距离使用tanh。

对F6输出`x[k]`及模板`c[j][k]`：

```text
D[j] = sum_k (x[k] - c[j][k])²
预测 = argmin_j D[j]
L = D[target] + log(exp(-J) + sum_j exp(-D[j]))
p[j] = exp(-D[j]) / (exp(-J) + sum_i exp(-D[i]))
dL/dD[j] = (j == target) - p[j]
dL/dx[k] = 2 * sum_j (dL/dD[j]) * (x[k] - c[j][k])
F6.d[k] = (dL/dx[k]) * 激活导数(F6.y[k])
```

`J=10`是本实现选择的背景类别惩罚，不声称是论文实验的原值。
`rbfloss`和`rbfbp`共享稳定的log-sum-exp计算，距离与损失用double累加；
训练日志调用同一损失，原来的`cnn->e=y-t`已删除。
目前CLI和GUI始终从0–9中选择最小距离，尚未实现自动拒识。

## 可训练下采样 S2 / S4

每通道共享系数a、偏置b：`sum=窗口元素之和`，`z=a*sum+b`，
`y=1.7159*tanh((2/3)*z)`。2×2窗口的a初始化为0.25，b初始化为0。
`poolff`缓存窗口和；`poolbp`把dL/dy转换为dL/dz，并计算
`dscaleData=sum(d*窗口和)`、`dbasicData=sum(d)`。
传给窗口内各输入的梯度为`a*d`，再乘前一个卷积层的激活导数；不再固定除以4。
`cnnapplygrads`在反传完成后统一更新包括下采样在内的参数。
